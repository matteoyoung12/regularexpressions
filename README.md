# Лабораторная работа №2: «Проверка выражений на регулярность»

## Описание проекта
Интерактивный веб-инструмент («помощник»), предназначенный для:
1. Синтаксического анализа и проверки регулярных выражений на корректность («регулярность»).
2. Поиска вхождений регулярного выражения в произвольной текстовой строке.
3. Наглядного выделения (подсветки) найденных фрагментов текста.
4. Вывода детальных предупреждающих сообщений в случае некорректных выражений, пустых строк или отсутствия совпадений.

---

## ⚠️ Важнейшее требование задания: «Избегать использования regex»
В соответствии с требованием лабораторной работы:
> **«!!! Избегать использования regex»**

В проекте **ПОЛНОСТЬЮ ОТСУТСТВУЕТ** использование встроенного объекта JavaScript `RegExp`, методов `String.prototype.match`, `String.prototype.search`, а также регулярных литералов вида `/pattern/`.

Вся логика реализована в строгом объектно-ориентированном стиле (ООП / SOLID / GRASP):

### Объектно-ориентированная архитектура (ООП)

Вместо монолитного процедурного кода и антипаттерна «God Object» система разделена на специализированные классы с четкой ответственностью:

1. **Классификатор символов (`CharClassifier`):**
   - Инкапсулирует посимвольную классификацию (цифры, латиница, кириллица, пробельные символы, предопределенные классы). Никаких внешних библиотек и regex.
2. **Токенизация (`Token`, `TokenType`, `Lexer`):**
   - `Token`: объектная модель лексемы с позицией в строке и метаданными.
   - `Lexer`: класс лексического анализатора, управляющий курсором и чтением токенов, диапазонов `[a-z]` и квантификаторов `{n,m}`.
3. **Иерархия AST-узлов (`AstNode` и полиморфизм):**
   - Базовый класс: `AstNode`.
   - Наследники: `CharNode`, `DotNode`, `AnchorStartNode`, `AnchorEndNode`, `PredefinedClassNode`, `CharClassNode`, `QuantifierNode`, `GroupNode`, `AlternationNode`, `ConcatNode`, `EmptyNode`.
   - **Полиморфизм вместо условий (Replace Conditional with Polymorphism):** Устранена монолитная конструкция `switch-case`. Каждый узел сам инкапсулирует логику сопоставления (`testAt`) с поддержкой бэктрекинга (CPS) и формирование собственного описания (`describe`).
4. **Синтаксический анализатор (`Parser`):**
   - Реализует рекурсивный спуск, валидирует грамматику регулярных выражений и конструирует полиморфное дерево `AstNode`.
5. **Движок сопоставления (`RegexMatch`, `RegexMatcher`):**
   - `RegexMatch`: модель совпадения (`start`, `end`, `value`).
   - `RegexMatcher`: обход текста и поиск всех непересекающихся вхождений по построенному AST.
6. **Валидатор синтаксиса (`SyntaxValidator`):**
   - Проверяет корректность шаблона и собирает подробные ошибки с указанием номера символа.
7. **Фасад ядра (`CustomRegexEngine` — паттерн Facade):**
   - Предоставляет единый лаконичный интерфейс (`validateSyntax`, `execute`), координирующий работу компонентов.
8. **Архитектура интерфейса (`app.js` — MVC):**
   - `HtmlEscaper`: безопасное экранирование спецсимволов HTML.
   - `AlertView`: инкапсуляция отображения предупреждений и ошибок.
   - `ResultView`: рендеринг подсветки совпадений, таблицы и дерева AST.
   - `RegexAppController`: координатор событий и жизненного цикла веб-приложения.

| **Пользователь вводит произвольное выражение (не обязательно регулярное)** | Поле ввода для шаблона/выражения с поддержкой любых символов. |

| **В противном случае выдать сообщение об его отсутствии** | Если выражение корректно, но не найдено в тексте, отображается информационное предупреждение об отсутствии совпадений. |
| **Избегать использования regex** | 100% кастомный движок без `RegExp` / `match` / `search`. Автоматический тест подтверждает отсутствие regex в кодовой базе. |

## Поддерживаемые элементы регулярных выражений
- **Литеральные символы:** латиница, кириллица, знаки препинания, пробелы.
- **Экранирование спецсимволов:** `\.`, `\*`, `\+`, `\?`, `\\`, `\(`, `\)`, `\[`, `\]`, `\{`, `\}`, `\|`, `\^`, `\$`.
- **Предопределенные классы:**
  - `\d` / `\D` — цифры / не цифры
  - `\w` / `\W` — словообразующие символы / не словообразующие символы
  - `\s` / `\S` — пробельные символы / непробельные символы
  - `\t`, `\n`, `\r` — управляющие символы
- **Любой символ:** точка (`.`).
- **Якоря:** `^` (начало строки), `$` (конец строки).
- **Классы символов:** `[...]` и инвертированные `[^...]`, включая диапазоны `[a-z]`, `[0-9]`, `[А-Яа-я]`.
- **Квантификаторы:**
  - `*` — от 0 до бесконечности
  - `+` — от 1 до бесконечности
  - `?` — от 0 до 1 (необязательный)
  - `{n}` — ровно n раз
  - `{n,}` — от n раз
  - `{n,m}` — от n до m раз (с проверкой $n \le m$)
- **Группировка и альтернатива:** `(...)` и `a|b|c`.
